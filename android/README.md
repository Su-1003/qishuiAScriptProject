# 汽水音乐 AScript 安卓脚本

脚本在安卓手机上运行。打开汽水音乐后，手动进入第一条奖励广告，脚本等到界面出现「领取成功」再执行两步领取。如果启动时已经打开「领取奖励」弹窗，脚本会从弹窗继续。如果 App 接着打开下一条广告，脚本会继续处理。检测到「更多直播」时，脚本会尝试识别实际的关闭按钮，然后等待领取提示。

看到「再看 1 个提前享明日畅听」弹窗时，脚本会点击绿色的「立即解锁 明日畅听」。它会等到弹窗退出、识别到广告倒计时等提示后，再处理这条广告。你也可以从已打开的弹窗开始运行，每次运行最多自动点击一次该入口。

## 首次部署

1. 安装 [AScript 安卓版](https://www.ascript.cn/docs/android/download/)，在 App 中选用无障碍模式，按系统提示开启无障碍并允许截屏。
2. 手机和电脑连同一个 Wi-Fi。打开手机 AScript 的「开发者」，在电脑浏览器打开页面显示的局域网地址，进入 WebIDE 并新建一个安卓工程。可参照 [AScript 官方教程](https://www.ascript.cn/docs/android/guide/first/)。
3. 打开工程的 `__init__.py`，用本目录 [`__init__.py`](./__init__.py) 的全部内容替换，保存并点击运行。工程生成的其他文件按默认设置保留。
4. 保持手机竖屏。脚本打开汽水音乐后，在 App 内手动进入第一条奖励广告，例如点「免」后按界面提示开始观看。若手机已停在奖励广告、「领取奖励」或「明日畅听」弹窗，直接运行即可。需要结束时，点 AScript 的停止按钮。

## 运行设置

| 脚本顶部的设置 | 默认值 |
| --- | --- |
| `FIRST_AD_TIMEOUT` | 等待手动进入首个广告并识别到领取提示，最多 120 秒 |
| `NEXT_AD_TIMEOUT` | 后续每轮最多等待 75 秒 |
| `MAX_ROUNDS` | 每次运行最多执行 50 轮领取 |

脚本只在汽水音乐处于前台时点击识别到的按钮。短暂切出时暂停识别，最多等待 8 秒。全屏 OCR 漏读「领取成功」时，会补读广告顶部。领取后识别到下一条广告或明确的领取结果，脚本才会继续。倒计时支持「13秒后可领取奖励×」这类带关闭符号的文案。若直播间关闭后仍停在原界面，脚本间隔至少 3 秒重试一次。

如果页面外观或按钮文案不同，脚本会在等待超时后停止。日志中的次数表示脚本已完成的领取操作，实际听歌时长以汽水音乐页面为准。

本版在 realme Android 16 手机上连续验证了至少 11 次普通领取操作。直播间关闭有真机记录，重试和「明日畅听」流程有模拟测试。若停在广告或领取页，可保留该页截图和 AScript 的最后几行日志，用于确认应匹配的按钮。

流程参考 [原 iOS 仓库](https://github.com/wei6718189/qishuiAScriptProject)。安卓包名参照 [小米应用商店](https://app.mi.com/details?id=com.luna.music)，OCR 接口参照 [AScript 安卓文档](https://www.ascript.cn/docs/android/api/screen/ocr/)。
